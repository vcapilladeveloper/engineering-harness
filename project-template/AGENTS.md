# Agent Instructions

This repository uses the Human-Centered Engineering Harness.

Before performing software changes:

1. Read `.ai/WORKFLOW.yaml`.
2. Read `.ai/PROJECT_CONTEXT.md`.
3. Read `.ai/ARCHITECTURE.md`.
4. Read `.ai/CODE_STYLE.md`.
5. Read `.ai/HANDOFF.md` when continuing previous work.

All software changes must follow the software-change workflow.
Respect the configured Cognitive Engineering mode.
